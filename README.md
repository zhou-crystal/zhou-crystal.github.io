# zhou-crystal.github.io

Personal academic website. Plain HTML + CSS, no build step. GitHub Pages serves it from the `main` branch.

- `index.html`: all page content
- `style.css`: styling (supports light and dark mode)
- `images/`: profile photo and project thumbnails (the current files are placeholders)
- `cv.pdf`: add your CV here; the "CV" link points to it

To preview locally: `python3 -m http.server` then open http://localhost:8000

Layout inspired by [Jon Barron's website](https://jonbarron.info).
